# Ghana Events

A React website with 4 pages: Home, Events, About and Contact.

## How to run
1. Install Node.js
2. Run `npm install`
3. Run `npm run dev` and open the link it shows

## Folders
- `src/pages` - the 4 pages
- `src/components` - Navbar, Footer and EventCard
- `src/data/events.js` - the list of events
- `src/styles.css` - all the styling
